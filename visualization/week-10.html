Scope of the Week

Week 10 combines practical Seaborn distribution plots, visualization-selection questions, a Titanic workshop case study, and a live introduction to Jupyter Notebook and Python basics.

The central analytical principle is:

Choose a visualization that preserves the structure needed to answer the question, while keeping the result readable and no more complex than necessary.

Part I — Visualizing Distributions with Seaborn

1. Why Study a Variable’s Distribution?

Understanding distribution is an early step in data analysis or modelling. Distribution plots quickly help answer:

  • What range do the observations cover?
  • What are the central tendencies?
  • Is the distribution heavily skewed?
  • Is there evidence of bimodality or multiple modes?
  • Are there significant outliers?
  • Do these features change across subsets defined by other variables?

Seaborn’s distribution module includes axes-level functions such as histplot(), kdeplot(), and rugplot(). Figure-level functions such as displot(), jointplot(), and pairplot() organize one or more axes-level plots. A figure-level function can create a grid of subplots; this is why displot() supports row and col faceting.

2. Histogram

Definition and purpose

A histogram divides the axis of a numerical variable into discrete bins. The height of each bar shows the number of observations falling in that bin. It is one of the most common ways to visualize a distribution and can be univariate or bivariate/conditioned through Seaborn semantics.

Core displot() parameters

Parameter Meaning / exam point
data Input structure: Pandas DataFrame, NumPy array, mapping, or sequence.
x, y Variables/vectors assigned to plot axes.
hue Semantic variable mapped to colour; draws a distribution for each unique category.
row, col Variables defining subsets displayed in different rows or columns of a facet grid.
kind Chooses the underlying distribution approach. For a histogram, use kind="hist" or rely on the histogram default in the demonstrated context.
legend Boolean controlling whether the legend is displayed.
palette Colour method for hue levels; may be a string, list, dictionary, or supported Matplotlib colour map/palette.
binwidth Directly sets bin width.
element Changes bar representation, e.g. "bars" versus "step".
multiple Controls how multiple hue distributions relate: layered, stacked, or dodged.

Demonstrated workflow: Penguins dataset

import matplotlib.pyplot as plt
import seaborn as sns

penguins = sns.load_dataset("penguins")
penguins.head()

Columns inspected in the lesson included species, island, bill_length_mm, bill_depth_mm, flipper_length_mm, body_mass_g, and sex. Always inspect the dataset and copy column names accurately.

Basic histogram:

sns.displot(data=penguins, x="flipper_length_mm")

The demonstrated combined distribution suggested that a common flipper length was around 195 mm, but more importantly it appeared bimodal. Therefore, one central value did not describe the entire distribution well.

Bin width: a major interpretive caution

sns.displot(data=penguins, x="flipper_length_mm", binwidth=3)
  • Bin size can materially change the apparent pattern.
  • Bins that are too wide may hide genuine structure.
  • Bins that are too narrow may create apparent features from random variability.
  • Seaborn selects defaults using information such as variance and sample size, but automatic rules make assumptions about the data.
  • Instructor emphasis: do not rely blindly on the default. Check whether the interpretation remains consistent across several reasonable bin widths.
  • With binwidth=3, bin edges progress in intervals of three units.

Explaining bimodality with conditional subsets

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species"
)

Assigning species to hue produces a separately coloured histogram for each species. The species-level distributions explain much of the apparent bimodality in the pooled histogram. This illustrates a general lesson: a combined distribution can conceal different subgroup distributions.

Ways to display multiple histograms

Layered/default

Separate hue distributions are drawn on the same axes. This supports direct comparison but overlapping bars may be difficult to distinguish.

Step element

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    element="step"
)

The step outline can reduce visual obstruction compared with filled overlapping bars.

Stack

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    multiple="stack"
)
  • Components are placed vertically on one another.
  • The total outline corresponds to the full histogram.
  • It emphasizes the part-to-whole relationship.
  • Caveat: it may obscure each subgroup’s shape or mode because only the baseline group has a common zero baseline.

Dodge

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    multiple="dodge"
)
  • Bars move horizontally and become narrower.
  • Overlap is removed and bar heights remain directly comparable.
  • Best when the categorical variable has only a small number of levels; many categories make the display crowded.

Faceting: separate subplots

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    col="sex"
)

Because displot() is figure-level, col="sex" creates one row with separate columns for male and female distributions. Using row would arrange them vertically. Separate subplots represent each subset clearly, but make direct point-by-point comparison somewhat harder than a shared plot.

Colouring faceted plots:

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    col="sex",
    hue="sex",
    palette="pastel"
)

The lesson explicitly noted that hue must be set when a palette is intended to map distinct colours to categories.

Exam-ready comparison of multiple-histogram strategies

Strategy Main strength Main limitation Best use
Layer Direct comparison on one axes Overlap Few transparent or outline distributions
Step Less obstruction Exact areas may be less visually forceful Comparing shapes
Stack Part-to-whole emphasis Individual modes/shapes obscured Composition by bin
Dodge Heights remain comparable Crowded with many levels Small number of categories
Facet (row/col) Each subset is clear Harder direct comparison; more space Detailed subgroup inspection

3. Kernel Density Estimation (KDE)

Definition

A histogram approximates an underlying probability density by binning and counting observations. Kernel density estimation solves the same broad problem differently: it smooths observations, commonly using a Gaussian/normal kernel, to produce a continuous density estimate.

KDE resembles a smoothed histogram, but it is an estimate rather than a display of literal bin counts. It can introduce distortions, especially near bounded data or when smoothing is poorly chosen.

Bandwidth: the central KDE concept

Bandwidth controls the width/standard deviation of the smoothing kernel and therefore the smoothness of the KDE curve.

  • Over-smoothed KDE: may erase meaningful peaks, skewness, or other real features.
  • Under-smoothed KDE: may turn random noise into false bumps or apparent structure.
  • Default bandwidth rules tend to work best when the true distribution is smooth, unimodal, and roughly bell-shaped.
  • Robust practice is to increase and decrease bandwidth and check whether substantive conclusions persist.

Bandwidth in KDE is analogous to bin width in a histogram.

Major kdeplot() parameters

Parameter Meaning
data DataFrame, NumPy array, mapping, or sequence.
x, y Variables/vectors positioned on the axes.
hue Maps categories to different colours/density curves.
palette Sets category colours.
bw_method String or scalar specifying how the base smoothing bandwidth is determined.
bw_adjust Numeric multiplier applied to the bandwidth selected by bw_method; larger values produce smoother curves.
multiple Controls arrangement of multiple densities, including stacking.
alpha Controls transparency.
linewidth Controls outline width; 0 removes the visible outline in a filled display.

Demonstrated code and interpretation

penguins = sns.load_dataset("penguins")

sns.kdeplot(
    data=penguins,
    x="flipper_length_mm"
)

Bandwidth experiments:

sns.kdeplot(
    data=penguins,
    x="flipper_length_mm",
    bw_adjust=0.2
)

The lesson compared values such as 0.2, 0.3, and 0.6: increasing bw_adjust made the curve smoother; reducing it made the curve more jagged.

Species-specific KDEs:

sns.kdeplot(
    data=penguins,
    x="flipper_length_mm",
    hue="species"
)

Filled/stacked aesthetic variation:

sns.kdeplot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    multiple="stack",
    palette="crest",
    fill=True,
    alpha=0.5,
    linewidth=0
)

This shows how category, colour, stacking, transparency, and line width can jointly improve readability. Aesthetics must not substitute for checking bandwidth validity.

4. Box Plot / Box-and-Whisker Plot

Definition and components

A box plot displays the three quartile values—lower quartile (Q1), median (Q2), and upper quartile (Q3)—together with extreme values.

The interquartile range is:

\[ IQR = Q3 - Q1 \]

Whiskers extend to observations within 1.5 IQR of the lower and upper quartiles. Observations outside that range are shown individually. Hence, displayed outlier points correspond to actual observations.

Two Seaborn methods

  1. Axes-level sns.boxplot().
  2. Figure-level sns.catplot(kind="box").

Important boxplot() parameters

Parameter Meaning
data Input DataFrame, array, mapping, or sequence.
x, y, hue Long-form plotting variables and nested category semantics.
order, hue_order Lists specifying the plotted order of categorical levels.
orient Explicitly overrides inferred vertical/horizontal orientation.
palette Category colour mapping.
fill False produces an outline/line-art style.
gap Adds space between clustered elements, e.g. gap=0.1.
color, linecolor, linewidth Modify fill, outline colour, and outline thickness.

Demonstrated Titanic workflow

import matplotlib.pyplot as plt
import seaborn as sns

titanic = sns.load_dataset("titanic")
titanic.head()

Variables emphasized included age, alive, and class.

One-variable plot:

sns.boxplot(data=titanic, x="age")

Grouped horizontal plot:

sns.boxplot(data=titanic, x="age", y="class")

Nested vertical grouping:

sns.boxplot(
    data=titanic,
    x="class",
    y="age",
    hue="alive"
)

The categorical class on x and numeric age on y produces vertical boxes; hue="alive" nests survival groups within each class.

Custom categorical colours:

sns.boxplot(
    data=titanic,
    x="class",
    y="age",
    hue="alive",
    palette=["red", "green"]
)

In the instructor’s intended semantic scheme, red represented not alive and green represented alive. Always verify hue-order before assuming which colour maps to which level.

Outline and spacing:

sns.boxplot(
    data=titanic,
    x="age",
    y="class",
    hue="alive",
    fill=False,
    gap=0.1
)

Other aesthetic controls demonstrated included color, linecolor, and linewidth (e.g. linewidth=0.75).

Orientation inference

Seaborn normally infers orientation from variable types:

  • categorical x + numerical y → vertical boxes;
  • numerical x + categorical y → horizontal boxes.

orient can override the default, which is especially useful when inference is ambiguous.

catplot(kind="box")

sns.catplot(
    data=titanic,
    x="class",
    y="age",
    kind="box"
)

Swapping the assignments changes the orientation:

sns.catplot(
    data=titanic,
    x="age",
    y="class",
    kind="box"
)

When to use boxplot() versus catplot()

Use boxplot() when… Use catplot(kind="box") when…
A direct, straightforward axes-level box plot is sufficient. Multiple/faceted box plots are needed by categorical variables.
Fine Matplotlib axes control is wanted. Consistency with other Seaborn categorical plots is valuable.
Performance matters on large data; it is lighter. You may switch among box, strip, violin, and other categorical kinds.

5. Violin Plot

Definition

A violin plot combines features of a box plot and a density plot:

  • vertical/horizontal spread shows the data range;
  • width shows estimated density at each value;
  • median and quartiles may be displayed inside;
  • the smooth density shape makes skewness, bimodality, and density variation easier to see than in a simple box plot.

Like a box plot, it compares distributions across categories; unlike a box plot, its outer shape is based on a KDE of the underlying distribution.

When to use it

  • Comparing the distributions of multiple groups, e.g. age across passenger classes.
  • Revealing shape, skewness, bimodal tendencies, or local density differences.
  • Showing both summary statistics and fuller distributional shape in one view.

Major parameters

Parameter Meaning
data Dataset. With no x/y it may be interpreted as wide form; with x/y, long form is expected.
x, y, hue Plotting and grouping variables.
orient Fixes vertical/horizontal orientation and overrides inference; useful when both variables are numeric.
bw_method Method for calculating kernel bandwidth.
bw_adjust Numeric multiplier for bandwidth; larger means smoother density.
fill False produces outline style.
palette Sets hue colours.

All KDE bandwidth cautions also apply to violin plots.

Positional/vector versus keyword/data-frame argument style

Vector style shown in the lesson:

df = sns.load_dataset("titanic")
sns.violinplot(x=df.age)

Keyword/data-frame style:

sns.violinplot(data=df, x="age")

Difference:

  • Vector style extracts the Series first and passes it directly.
  • Keyword style passes the entire DataFrame, then names the column inside the function.
  • Both can generate the same visual result; the demonstration introduced both calling styles.

Bivariate grouping and orientation

sns.violinplot(data=df, x="age", y="class")  # horizontal
sns.violinplot(data=df, x="class", y="age")  # vertical

Seaborn prefers to group by the categorical variable. Swapping categorical/numeric x and y assignments changes orientation.

Nested grouping, line-art, and palette:

sns.violinplot(
    data=df,
    x="class",
    y="age",
    hue="alive",
    fill=False
)

sns.violinplot(
    data=df,
    x="class",
    y="age",
    hue="alive",
    palette=["red", "green"]
)

catplot(kind="violin") and faceting

sns.catplot(
    data=df,
    x="class",
    y="age",
    hue="alive",
    kind="violin"
)

Side-by-side facet columns:

sns.catplot(
    data=df,
    x="class",
    y="age",
    hue="alive",
    col="alive",
    kind="violin",
    palette=["red", "green"]
)

Using row="alive" instead places the not-alive and alive facets one above the other. The same selection logic used for box plots applies: use violinplot() for a straightforward axes-level plot and catplot() for figure-level faceting and consistency across categorical plot types.

6. Distribution-Plot Comparison

Plot Encodes Main strength Main risk/limitation
Histogram Counts in bins Concrete frequency structure Sensitive to bin width
KDE Continuous estimated density Smooth shape comparison Sensitive to bandwidth; may imply density outside valid bounds
Box plot Quartiles, median, whiskers, outliers Compact robust summary across groups Hides detailed/multimodal shape
Violin plot KDE shape plus internal summary Shows summary and full shape Bandwidth-dependent; width may be unfamiliar
Rug plot One tick per observation Preserves individual positions Overplotting with large samples; weak summary

Likely exam comparison: histogram bin width and KDE/violin bandwidth play analogous roles. Both must be varied to check robustness.

Part II — Quiz Concepts: Choosing and Customizing Visualizations

7. Scatter Plots and Marker Customization

A scatter plot displays the relationship between two numeric variables; each point is one observation. For the Tips dataset, plotting total_bill against tip preserves each meal’s paired values and can reveal trend/correlation, clusters, and outliers such as a high bill with an unusually low tip.

sns.scatterplot(data=df, x="total_bill", y="tip")

Preserve hue colours while changing every marker

sns.scatterplot(
    data=df,
    x="x",
    y="y",
    hue="category",
    marker="D"
)

marker="D" makes all observations diamonds while leaving hue-based category colours and the corresponding legend mapping intact.

Do not use style="category" if the goal is one common marker: style deliberately maps categories to different marker shapes. Use it only when both colour and shape distinction are desired.

Changing the palette when only shape needs changing is also incorrect because it changes the established colour encoding.

Why not aggregate for relationship analysis?

A bar chart of average or total tips destroys the individual (total_bill, tip) pairings. Bar charts summarize; scatter plots preserve observation-level relationships.

8. Pair Plot and PairGrid

Pair plot

A pair plot displays every pairwise relationship among selected numerical variables in a matrix:

  • off-diagonal cells show bivariate relationships, commonly scatter plots;
  • diagonal cells show each variable’s univariate distribution, commonly histogram or KDE.

For total_bill, tip, and size, it shows every two-variable combination plus three diagonal distributions. It is preferred for broad multivariate exploration and discovering correlations/patterns.

PairGrid

PairGrid provides more control over what is mapped into the grid:

g = sns.PairGrid(df)
g.map_offdiag(sns.scatterplot)
g.map_diag(sns.histplot)

Use it when different functions or settings are needed on diagonal and off-diagonal panels.

PairGrid versus FacetGrid

Feature PairGrid FacetGrid
Purpose Compare variables with other variables Compare subsets/groups
Rows/columns represent Variables Categorical levels
Typical use Correlation and multivariate exploration Conditioned plots, e.g. male vs female

Memory cue: PairGrid = variable × variable; FacetGrid = group-conditioned panels.

9. Related Plot Choices

  • Scatter plot: one pair of numerical variables.
  • Pair plot / PairGrid: many numerical-variable relationships.
  • Distribution plot: one variable’s distribution.
  • Joint plot: one numerical pair plus marginal distributions.
  • Correlation heatmap: compact numerical summary of correlations.

A correlation heatmap is compact and quickly communicates strength/direction of linear association, but it does not show individual observations, clusters, nonlinear shape, or unusual points.

10. 3D Visualization

A 2D plot represents (x, y); a 3D plot represents (x, y, z). A third variable can reveal separation or clustering hidden in a 2D projection—for example, age, income, and spending considered simultaneously.

Limitations:

  • Occlusion: points hide behind one another.
  • Perspective distortion: the viewing angle affects apparent distances and patterns.
  • Interaction requirement: rotation may be required for understanding.
  • It does not change the data or create a new relationship; it only changes representation.
  • It can show association or clustering, but does not prove causation or explain why groups exist.

Use 3D only when the third variable materially answers the analytical question. Prefer 2D when it communicates the result more clearly; never use 3D merely for decoration.

11. Visualization Selection Framework

Requirement Suitable visualization
Relationship between two numeric variables Scatter plot
All pairwise relationships among many numeric variables Pair plot / PairGrid
One-variable distribution Histogram, KDE, rug plot
Distribution plus categorical comparison Box or violin plot
One numeric pair plus marginal distributions Joint plot
Three-variable structure hidden in 2D Consider 3D scatter
Compact numerical correlation overview Correlation heatmap
Separate category-conditioned views FacetGrid / figure-level row or col

Common exam traps:

  1. Changing hue/palette when only the marker should change.
  2. Using a bar chart where observation-level relationships must be preserved.
  3. Choosing 3D because it looks impressive rather than because z adds insight.
  4. Confusing PairGrid with FacetGrid.

Part III — Titanic Workshop Case Study

12. Environment Setup

import matplotlib.pyplot as plt
import seaborn as sns

plt.rcParams["figure.figsize"] = [8, 6]
sns.set_style("darkgrid")

titanic = sns.load_dataset("titanic")

What each statement does

  • matplotlib.pyplot provides foundational plotting and low-level figure/axes control.
  • Seaborn provides a high-level statistical visualization interface built on Matplotlib.
  • plt.rcParams["figure.figsize"] = [8, 6] sets the default figure width and height in inches; it affects appearance/readability, not the data, aggregation, or statistical result.
  • sns.set_style("darkgrid") changes the visual theme/background and grid. Other common styles include white and whitegrid.
  • sns.load_dataset("titanic") loads Seaborn’s example Titanic data.

13. Rug Plot

A rug plot places a small tick along an axis for each observation.

sns.rugplot(data=titanic, x="age")

It preserves raw observation positions and helps identify concentration, gaps, clusters, and overall distribution. Because every observation is shown, it provides detail that aggregate plots omit.

Limitations:

  • ticks overlap heavily in large/dense datasets;
  • it does not directly provide a strong category summary or central tendency;
  • unfamiliar audiences may find it harder to interpret;
  • it is often most effective as a supporting layer or separate exploratory panel.

14. Seaborn Bar Plot and Default Aggregation

sns.barplot(x="pclass", y="fare", data=titanic)

For each passenger-class category, Seaborn’s bar plot displays the mean fare by default (with uncertainty/error information depending on version/settings). The case-study interpretation was that first-class passengers had a substantially higher average fare than second- and third-class passengers.

A bar plot is useful for:

  • clear category comparison;
  • concise summary communication;
  • presentations and executive audiences.

It does not show every passenger’s fare, within-class spread, clusters, skewness, or individual outliers. A crucial exam point is to know the estimator/default aggregation rather than incorrectly describing each bar as a total or raw value.

15. Choosing Between Bar, Rug, and Combined Views

Option Advantage Limitation
Bar plot only Simple comparison of mean fare by class Hides raw distributions and variation
Rug plot only Preserves all age observations and clusters Weak category summary; can become cluttered
Combined/multi-panel Provides summary plus detail More complex and takes more space

The suggested teaching sequence is a multi-panel or staged approach:

  1. Begin with mean fare by passenger class to establish the main summary.
  2. Show the age rug plot to teach raw distribution and clustering.
  3. Explain how summary and detailed views complement each other and may motivate deeper conditioned analysis.

Do not literally overlay unrelated variables or incompatible scales merely because both plots are available. Separate panels are normally clearer for mean fare by class and age distribution. If investigating whether older passengers cluster in higher-fare classes, use an appropriate relationship/conditioned plot rather than inferring that relationship from two unrelated marginals.

Audience matters:

  • Beginners: introduce the familiar summary first, then explain rug marks.
  • Analysts: show raw detail and complementary panels.
  • Decision-makers: emphasize the principal comparison and avoid unnecessary complexity.

The general principle is: a summary view states what is happening; a detailed exploratory view helps investigate why and reveals what aggregation hides.

17. Python and Jupyter Architecture

  • Python is the language/engine used to write and run code.
  • Jupyter Notebook is the browser-based front end where code, text, and results are entered/displayed.
  • The kernel is the background engine: it executes code, calculates results, and sends output back to the browser.
  • In a local installation, the browser is served from the same computer (localhost, commonly on a port such as 8888).
  • Do not close the background server/kernel window while using the notebook; the browser front end will lose its execution backend and stop working.

Installation routes mentioned:

  1. Install Anaconda, which bundles Python/Jupyter and supporting packages.
  2. Install Python from python.org, then install Jupyter separately.

Other environments such as VS Code or PyCharm are acceptable for experienced users, but the instructor demonstrates in Jupyter. Verify installation/version from the command line (the lecture mentioned version checks such as pip --version). A desktop/taskbar shortcut may simplify starting Jupyter.

18. Creating and Navigating a Notebook

  • The Jupyter home page behaves like a file explorer, showing files and folders.
  • Use New → Python 3 / Notebook to create a notebook.
  • Notebook files use the .ipynb extension, analogous to .docx, .xlsx, and .pptx for other applications.
  • Rename an “Untitled” notebook by clicking its title.
  • Explore File, Edit, View, Run, Kernel, and Help menus.
  • The instructor stressed active practice and trial-and-error rather than only listening.

19. Cell Types

Code cell

  • Default cell type.
  • Accepts executable Python.
  • Recognizable by In [ ] / square brackets.
  • Output appears below the cell.
  • The execution number records execution order, not physical top-to-bottom position.
print("Hello world")

Python is case-sensitive: the lesson’s capitalized Print produced an error; print must be lowercase. Strings must be quoted.

Execution:

  • Shift+Enter: execute and move to/select the next cell.
  • Ctrl+Enter: execute while remaining on the current cell.
  • Plain Enter inserts a new line while editing.

Errors appear visibly (commonly red); read them to diagnose syntax or name problems.

Markdown cell

A Markdown cell formats explanatory text rather than running it as Python. It lacks code-cell execution brackets. It enables notebooks to combine narrative, headings, instructions, expected results, and code.

Examples:

# Main heading
## Second-level heading
*italic text*
**bold text**

The instructor noted that heading levels can extend through six levels. Execute/render the Markdown cell to see formatting.

Raw cell

A raw cell preserves content without executing it or rendering it as Markdown. It is less commonly used and may carry material for another conversion/application, such as notebook conversion or LaTeX-related workflows.

20. Comments, Modes, and Execution State

Python comments

# Demo of basic Python addition
x = 20
y = 30
print(x + y)

Text placed directly in a code cell is treated as Python and may cause a syntax error. Prefix non-executable explanatory text with #. Comments document code blocks, aid debugging, and help future readers locate assignments, input logic, calculations, and other sections in long programs.

Edit and command/view behaviour

Clicking/double-clicking inside a cell places it in edit mode. After execution, rendered Markdown or output is shown; select/edit the cell again to change its source.

Execution order and dependencies

If a calculation cell is run before the cells that define its variables, Python reports that the variables are not defined.

x = 10
y = 20
r = x + y

The assignments must execute before r = x + y. Restarting the kernel clears in-memory state; cells then need to be rerun in the correct order. Clearing output changes what is displayed, while restarting affects live state.

[*] indicator

  • In [*] means the kernel is busy executing that cell.
  • A number appears when execution finishes.
  • Long calculations or loops may show the star for some time.
  • A persistent star may indicate a very long operation or an infinite loop; interrupt or restart the kernel when necessary.

21. Python Data Types

The lecture focused on seven major types:

Type Meaning Example / syntax
String (str) Text x = "Hello world"
Integer (int) Whole number, positive/negative/zero age = 25
Float (float) Decimal/floating-point number height = 5.9
Boolean (bool) True or False is_student = True
List (list) Ordered collection, written with square brackets colors = ["red", "green", "blue"]
Tuple (tuple) Ordered collection commonly used for fixed groups/coordinates, written with parentheses dimensions = (1920, 1080)
Dictionary (dict) Key–value pairs, written with curly braces and colons student = {"name": "Senthil", "age": 25}

Use type() to inspect a value:

print("x is", type(x))
print("age is", type(age))

Python uses dynamic type inference: unlike languages requiring a prior declaration, it infers a variable’s type from the assigned value. height = 5.9 is a float, whereas height = 5 is an integer.

Review-Week Augmentation

Scatter, line, and bubble distinctions

A scatter plot shows the relationship between two quantitative variables—for example Advertising vs Sales, Height vs Weight, or Experience vs Salary. It reveals correlation/association, clusters, outliers, and nonlinear structure without requiring an inherent order.

Chart Encodes Implied structure
Scatter x-position + y-position Association; no required order
Line ordered x + connected y Progression, usually time
Bubble x + y + bubble area; optional colour Association with a third/fourth variable

Do not connect scatter points unless the order or path is analytically meaningful. Do not infer causation from correlation.

Perceptual precision and dimensionality

Aligned 2-D position is easier to compare than bubble area or perspective-distorted depth. A 3-D plot may reveal hidden structure interactively, but occlusion, perspective, and dependence on rotation can make it worse than 2-D alternatives. Prefer pair plots, faceting, colour/shape, or small multiples when they answer the question more clearly and accessibly.
