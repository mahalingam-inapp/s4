Part I — Seaborn Scatter Plots

1. Meaning and purpose

A scatter plot is a mainstay of statistical visualization. It depicts the joint distribution of two variables as a cloud of points. Each point represents one observation, and its horizontal and vertical positions represent that observation’s values for two variables.

Scatter plots help the eye infer:

  • Whether a meaningful relationship exists.
  • Direction: positive, negative, or absent.
  • Form: linear, curved, clustered, or irregular.
  • Strength: tight or diffuse pattern.
  • Outliers and unusual subgroups.

When both variables are numeric, Seaborn’s basic function is sns.scatterplot().

2. Core scatterplot() parameters

Parameter Meaning Important behavior
data Input data structure Accepts a Pandas DataFrame, NumPy array, mapping, or sequence. It may be long-form vectors referenced by name or wide-form data internally reshaped by Seaborn.
x, y Variables determining x- and y-axis positions May be vectors or keys/column names in data.
hue Maps a grouping variable to point color Can be categorical or numeric. Categorical values receive distinct colors; numeric values normally receive a quantitative/continuous color mapping.
size Maps a grouping variable to marker area Can be categorical or numeric; mapping behavior differs between these cases.
style Maps groups to marker shapes Always interpreted categorically, even if the source variable has a numeric dtype.
palette Controls colors used for hue Can be a palette name/string, list, or dictionary mapping levels to colors. It can force a chosen categorical palette.
markers / marker Controls marker forms A single marker changes all points. With style, marker specifications can be Boolean, a list, or a mapping from style levels to markers.
color Sets one color for all points A color name or abbreviation may be used when no semantic color distinction is required.

Semantic encoding distinction

  • Position (x, y) encodes the two principal quantitative variables.
  • Color (hue) can encode a third variable.
  • Area (size) can encode another variable.
  • Shape (style) can encode a category and improves accessibility when color alone is insufficient.

Using both hue and style for the same category creates redundant encoding. This often makes a chart easier to interpret, including for viewers who cannot reliably distinguish colors.

3. Demonstration using the tips dataset

import matplotlib.pyplot as plt
import seaborn as sns

tips = sns.load_dataset("tips")
tips.head()

Important columns mentioned: total_bill, tip, sex, smoker, day, time, and size.

Basic plot

sns.scatterplot(data=tips, x="total_bill", y="tip")

Interpretation: total bill is plotted on the x-axis and tip on the y-axis. This is the plain plot before semantic/aesthetic parameters are added.

One fixed color and marker

sns.scatterplot(
    data=tips, x="total_bill", y="tip",
    color="red", marker="x"
)

Changing color changes all points; changing marker changes their common shape.

Categorical hue

sns.scatterplot(data=tips, x="total_bill", y="tip", hue="time")

Lunch and dinner observations are differentiated by color.

Same variable for hue and style

sns.scatterplot(
    data=tips, x="total_bill", y="tip",
    hue="time", style="time"
)

Each time category receives both a color and marker form. This is more accessible than color alone.

Different variables for hue and style

sns.scatterplot(
    data=tips, x="total_bill", y="tip",
    hue="day", style="time"
)

Color and marker now vary independently. This communicates two categorical dimensions but also increases cognitive load; legends and category counts must remain manageable.

Numeric hue

sns.scatterplot(
    data=tips, x="total_bill", y="tip",
    hue="size", style="time"
)

Because size is numeric, the default hue mapping is quantitative rather than a set of unrelated category colors.

Force a categorical palette

sns.scatterplot(
    data=tips, x="total_bill", y="tip",
    hue="size", style="time", palette="deep"
)

The lecture uses palette="deep" to demonstrate forcing a selected palette. Exam point: a numeric hue normally uses a quantitative palette, whereas a named categorical palette changes that presentation.

Numeric marker size

sns.scatterplot(
    data=tips, x="total_bill", y="tip",
    hue="size", size="size", style="time"
)

Marker areas now vary with party size. Do not confuse the dataset column size with the plotting parameter size; here the parameter maps that column to point area.

4. Multiple scatter plots with relplot()

sns.relplot() is a figure-level relational plotting function. It combines a relational plot such as a scatter plot with faceting across categories.

sns.relplot(
    data=tips,
    x="total_bill",
    y="tip",
    col="time",
    hue="day",
    style="day",
    kind="scatter"
)

Here:

  • col="time" creates separate column panels for Lunch and Dinner.
  • hue="day" colors observations by day.
  • style="day" varies marker shape by day.
  • kind="scatter" explicitly requests scatter plots.
  • With no row, categories are laid out as columns in one row.

Why relplot() is described as safer than direct FacetGrid

FacetGrid is powerful but lower-level and requires more manual setup. If semantic mappings are configured separately, the same category could accidentally receive different colors or markers in different facets.

relplot() sits on top of a facet grid and automatically synchronizes semantics—color/hue, size, and marker style—across the entire grid. Therefore:

  • The same category has the same visual meaning in every panel.
  • Legends and category mappings remain consistent.
  • The chance of accidental mismatch and reader confusion is reduced.

Likely exam point: “Safer” does not mean that FacetGrid is incorrect. It means relplot() automatically manages consistent semantic mappings, whereas direct FacetGrid use may require manual synchronization.

Part II — Heatmaps

5. Definition, purpose, and data requirement

A heatmap is a matrix-style graphical representation in which individual data values are represented by color intensity. It is widely used to reveal:

  • Patterns.
  • Correlations.
  • Trends.
  • High/low-value regions in a matrix.

Critical prerequisite emphasized by the instructor: Both rows and columns must carry meaningful information. A raw observation index such as 0, 1, 2, … usually does not create a meaningful matrix for a heatmap.

6. Important sns.heatmap() parameters

Parameter Function
data Any rectangular dataset to visualize.
vmin, vmax Anchor the lower and upper values mapped into the colormap; control the color scale’s numeric range.
cmap Maps data values into color space. Accepts a Matplotlib colormap name/object or suitable color specification. Optional.
annot If True, writes the value inside each cell; a rectangular annotation dataset may also be supplied.
linewidths Width of lines separating cells.
linecolor Color of cell-separating lines.

Practical caution

For comparable heatmaps, use consistent vmin and vmax. Otherwise identical colors in separate charts might represent different values.

7. Titanic correlation heatmap workflow

Step 1: Load and inspect

import matplotlib.pyplot as plt
import seaborn as sns

titanic_data = sns.load_dataset("titanic")
titanic_data.head()

The raw dataset has meaningful column names but observation-number rows. It also contains strings/categories such as sex, class, embarked, and Boolean-like values.

Step 2: Understand the failed direct correlation

Calling .corr() on mixed text and numeric data can fail because correlation requires numeric values and strings cannot simply be converted to floating-point values.

Step 3: Select numeric columns

titanic_numeric = titanic_data.select_dtypes(include="number")

The transcript identifies numeric variables such as survived, pclass, age, sibsp, parch, and fare (subject to the dataset/version).

Step 4: Create the correlation matrix

corr = titanic_numeric.corr()

This creates meaningful variable names on both axes. Diagonal values are 1 because each variable is perfectly correlated with itself.

Step 5: Plot and customize

sns.heatmap(corr)

sns.heatmap(corr, annot=True)

annot=True displays correlation coefficients in cells.

sns.heatmap(
    corr,
    annot=True,
    linewidths=5,
    linecolor="white"
)

This adds clearly separated cell borders.

sns.heatmap(corr, annot=True, cmap="coolwarm")

The lecture also demonstrates icefire. A diverging palette such as coolwarm is useful for correlations because it can distinguish values on opposite sides of a meaningful center.

8. Flights pivot-table heatmap workflow

Correlation is one way to form a meaningful matrix; pivoting is another.

Load data

flights = sns.load_dataset("flights")
flights.head()

Columns are year, month, and passengers. Raw observation rows are not the desired heatmap structure.

Pivot into meaningful axes

flights_pivot = flights.pivot_table(
    index="month",
    columns="year",
    values="passengers",
    observed=False
)
  • Rows become months.
  • Columns become years.
  • Cells contain passenger counts.
  • observed=False was added because Pandas warned that its default was deprecated and would change; reading warnings is important because they often specify the corrective action.

Plot

sns.heatmap(flights_pivot, cmap="coolwarm")

The heatmap makes growth patterns easy to see—for example, high passenger numbers in July/August and growth toward later years.

Reverse month order by reindexing

The initial table places January at the top and December at the bottom. To make January appear at the bottom of the plotted y-axis, reorder the source matrix:

month_order = [
    "Dec", "Nov", "Oct", "Sep", "Aug", "Jul",
    "Jun", "May", "Apr", "Mar", "Feb", "Jan"
]

flights_reordered = flights_pivot.reindex(month_order)
sns.heatmap(flights_reordered, cmap="coolwarm")

The exact month labels must match the dataset values (full names may be needed in some versions). The conceptual point is that plot order can be changed by transforming/reindexing the data before plotting.

9. Correlation versus pivot preparation

Method Use when Output meaning
Numeric selection + .corr() Comparing relationships among numeric variables Same variables on rows and columns; cells are correlation coefficients.
.pivot_table() Turning long/tabular observations into a two-dimensional business matrix One categorical/time dimension on rows, another on columns, and a measure in cells.

Part III — Styling Seaborn Figures

10. Why Seaborn styling exists

Matplotlib is highly customizable, but it may be difficult to know which low-level settings to change to produce an attractive chart. Seaborn provides customized themes and high-level interfaces that control Matplotlib figure appearance.

Calling sns.set_theme() switches to Seaborn defaults. Seaborn conceptually divides Matplotlib parameters into two independent groups:

  1. Style — aesthetic appearance, such as background, grid, and axis details.
  2. Context — scaling of plot elements so the figure suits its display setting.

11. Function pairs

Purpose Inspect/return dictionary Set defaults
Aesthetic style sns.axes_style() sns.set_style()
Scale/context sns.plotting_context() sns.set_context()

The first function in each pair returns a dictionary of parameters. The second updates Matplotlib defaults used by subsequent plots.

12. Five preset styles

  1. darkgrid — default Seaborn theme in the lecture; white/gray background with grid lines.
  2. whitegrid — similar grid support on white; useful when data elements are visually heavy.
  3. dark — dark/gray background without the full grid emphasis.
  4. white — clean white background.
  5. ticks — white style emphasizing tick marks.

Grid lines can make a plot function as a lookup table for quantitative values. In darkgrid, the subdued grid should not compete with the data marks.

13. Plotting contexts

Seaborn contexts scale fonts, markers, and line widths for use conditions:

  • paper — compact output.
  • notebook — default general notebook use.
  • talk — presentations; larger text and marks.
  • poster — largest scale for distance viewing.
sns.set_style("darkgrid")
sns.set_context("talk")

sns.scatterplot(
    data=tips,
    x="total_bill",
    y="tip",
    hue="day"
)
plt.title("Scatter plot with precise style and context settings")

Compared with the unstyled/default plot, the example has a visible dark grid plus larger fonts and points appropriate for a talk.

Exam distinction: Style changes what the plot looks like; context changes the scale of plot elements for the viewing situation.

14. Inspecting and resetting settings

sns.reset_defaults()

default_style = sns.axes_style()
default_context = sns.plotting_context()

print(default_style)
print(default_context)

The demonstration observes a white face color and a default font size around 10 after reset.

sns.set_style("darkgrid")
sns.set_context("poster")

current_style = sns.axes_style()
current_context = sns.plotting_context()

The changed style reports a light-gray/hexadecimal face color; the poster context shows a much larger font size (about 24 in the lecture). The dictionary does not necessarily print the human-readable preset name, so infer the setting from its parameter values.

15. Decluttering with despine()

Spines are the borders around a plot. All four borders may add visual clutter and are not always necessary.

sns.scatterplot(data=tips, x="total_bill", y="tip", hue="day")
sns.despine()

Default sns.despine() removes the top and right spines while retaining the left and bottom axes.

Offset

sns.despine(offset=10)

offset moves the surviving spines away from the data/plot area, creating a small visual gap.

Trim

The trim parameter limits surviving spines to the tick range rather than letting them span the full axis length.

Instructor emphasis: Decluttering is not deletion for its own sake. Remove borders or lines when they do not contribute meaning; retain them where multiple plots or the reading task makes boundaries useful.

Part IV — Quiz Concepts and Likely Exam Questions

16. Seaborn versus Matplotlib

Matplotlib

  • Foundational/static Python visualization library.
  • Provides figure creation, axes management, line/scatter plotting, and detailed low-level customization.
  • Popular for simplicity, versatility, and integration with other libraries.

Seaborn

  • Built on top of Matplotlib; Matplotlib is needed underneath it.
  • Offers attractive defaults, statistical visualizations, themes, semantic mappings, and strong DataFrame integration.
  • Does not replace Matplotlib. Seaborn creates/manages Matplotlib figures and axes, so Matplotlib commands can still set titles, labels, limits, and save output.

Why Seaborn is often preferred for appearance

  • Better default color palettes and themes.
  • Less code for grouped/statistical plots.
  • Direct mapping of DataFrame column names.
  • Convenient regression, categorical, pairwise, and faceted plots.

Pandas plotting is convenient for quick DataFrame plots but provides a thinner high-level interface. MATLAB is a separate numerical computing environment, not a Python visualization layer built over Matplotlib.

17. Scatter patterns and linear regression suitability

Good candidate

If the points follow an approximate straight line:

  • A positive slope means y tends to increase with x.
  • A negative slope means y tends to decrease with x.
  • A tight line-like cloud indicates a stronger linear relationship.

Such variables may be reasonable candidates for a linear regression model, subject to proper diagnostics.

Poor candidates or warning patterns

  • A curved pattern suggests a nonlinear relation.
  • A random cloud suggests little/no systematic association.
  • Clusters may indicate an unmodeled categorical factor.
  • Outliers may distort a fitted line.
  • Changing vertical spread may signal nonconstant variance.

A scatter plot suggests suitability; it does not by itself prove causality or validate every regression assumption.

18. Pair plots for variable selection

sns.pairplot() displays pairwise relationships among several numeric variables.

  • Off-diagonal cells: scatter plots for each variable pair; use them to inspect direction, form, strength, clusters, and outliers.
  • Diagonal cells: each variable’s own distribution, commonly a histogram or density curve.

For preliminary regression selection, identify the predictor–outcome pairs whose off-diagonal points most closely follow a straight line. A pair plot is exploratory evidence, not a substitute for correlation values, domain logic, feature leakage checks, or model diagnostics.

19. lmplot(), hue, and col

sns.lmplot() displays a scatter plot with a fitted linear regression relationship.

sns.lmplot(data=df, x="x", y="y", hue="group")

hue keeps groups in the same panel and distinguishes them by color. This supports direct visual comparison but can overlap.

sns.lmplot(data=df, x="x", y="y", col="group")

col creates separate side-by-side regression panels for each group. This reduces overlap and enables group-specific inspection.

hue col
Groups share one coordinate system/panel. Each category gets a separate panel.
Color distinguishes groups. Spatial separation distinguishes groups.
Good for direct comparison; may become crowded. Good for clarity; requires more space.

20. Matplotlib figure and axes creation

fig, axs = plt.subplots(2, 2, figsize=(10, 8), sharex=False)

This creates:

  • One Figure: the complete canvas/container.
  • Four Axes: individual plotting regions, accessed as axs[0,0], axs[0,1], axs[1,0], and axs[1,1].

plt.subplots() is preferred for organized multi-panel layouts because it creates the figure and axes together.

Global figure size

plt.rcParams["figure.figsize"] = (8, 4)

This sets the default width and height, in inches, for future figures. It does not resize an already-created figure and does not set axis data limits.

For a single explicit figure, use figsize=(width, height) in plt.subplots() or plt.figure().

21. Heatmap/axis clipping and misleading plots

A clipped plot displays only part of the available data range. Changing a colormap, removing variables, or merely increasing figure size does not correct a data-range clipping problem.

The correct response is to inspect and correct axis limits, for example with ax.set_ylim(...) or plt.ylim(...), while preserving the underlying data. In some Seaborn/Matplotlib heatmap rendering situations, explicitly resetting limits to cover the full matrix prevents first/last rows from appearing cut off.

sqrt(x) versus x³ example

  • sqrt(x) grows slowly and is defined over nonnegative real x in the usual real-number plot.
  • x³ grows quickly and may leave a narrow y-range almost immediately.
  • If the y-axis is clipped, only a small visible segment of x³ may appear and can be falsely interpreted as the function’s complete behavior.

Always examine:

  • x- and y-axis limits.
  • Whether the plotted domain is complete.
  • Labels and units.
  • Missing or hidden data.
  • Whether encodings preserve the intended meaning.
  • Whether visible evidence supports the conclusion.

Core quiz principle: Fix the visualization without altering/removing valid underlying data, and never interpret a clipped view as complete evidence.

Part V — UrbanTrend Retail Dashboard Case Study

22. Business requirement

Maria must create an executive sales dashboard in Jupyter using monthly data across products and regions. It should communicate:

  • Product A and Product B revenue trends.
  • Change in product mix across three categories.
  • Regional sales distribution.
  • A coherent executive summary that remains readable in print.

Tools: Pandas for data handling, NumPy for numerical operations, and Matplotlib for visualization.

23. Proposed 2×2 structure

fig, axs = plt.subplots(
    2, 2,
    figsize=(10, 8),
    sharex=False
)

axs[0, 0].plot(months, product_a)
axs[0, 1].plot(months, product_b)

axs[1, 0].stackplot(
    months, cat_X, cat_Y, cat_Z,
    labels=["X", "Y", "Z"],
    alpha=0.7
)

axs[1, 1].pie(
    region_sales,
    labels=regions,
    autopct="%1.1f%%",
    startangle=90
)

plt.tight_layout()
plt.savefig("dashboard.png")

Parameter meanings

  • figsize=(10, 8): overall canvas width and height; it does not change the data or the number of subplots.
  • sharex=False: each subplot keeps an independent x-axis. This is appropriate because the pie chart has no month axis.
  • tight_layout(): adjusts subplot spacing to reduce overlapping titles, labels, ticks, and legends.
  • alpha=0.7: makes stackplot areas partially transparent.
  • labels: supplies category/region names.
  • autopct="%1.1f%%": writes percentages to one decimal place in the pie.
  • startangle=90: rotates the starting slice to 90 degrees for a more deliberate orientation.

24. Choosing each chart

Line charts

Best for ordered time-series data. They reveal direction, growth/decline, peaks, dips, volatility, seasonality, and differences between products.

Stacked area plot

Shows both:

  • Overall total over time (top boundary).
  • How categories X, Y, and Z contribute to the total/product mix.

Limitations:

  • Only the bottom band has a stable zero baseline.
  • Middle/upper categories are harder to compare precisely.
  • Too many categories cause clutter.

Use a legend because color identifies category meaning.

Pie chart

Shows regional part-to-whole composition at a point in time. It is suitable for a small number of distinct categories and an approximate share story.

Limitations:

  • Small slices and similar angles are difficult to compare.
  • Detailed ranking is easier with a bar chart.
  • A pie chart may become too small inside a four-panel printed dashboard.

25. One dashboard versus split figures

One 2×2 figure Split into trend dashboard + regional figure
Single executive overview. Larger, clearer charts.
Easy file management and one savefig() call. Better print quality and focused storytelling.
Related time trends can be viewed together. Regional composition receives appropriate emphasis.
Pie may be too small; overall page may feel crowded. More output files must be named and managed.

Jamal’s “easy cross-comparison” argument is only partly valid. Product line charts and the stackplot share a time dimension and are directly comparable. The pie chart represents composition at one point and has no time axis; its comparison with the other charts is conceptual rather than direct. sharex=False reinforces that not all four charts share a common horizontal meaning.

26. Recommended decision

Create two outputs:

  1. Sales performance dashboard: Product A trend, Product B trend, and product-category mix.
  2. Regional sales breakdown: an enlarged regional composition plot.
fig1.savefig("sales_trends.png", dpi=300, bbox_inches="tight")
fig2.savefig("regional_sales.png", dpi=300, bbox_inches="tight")

This balances analytical flow, executive clarity, print readability, and implementation simplicity. If case constraints permit, replace the pie with a horizontal bar chart for easier ranking and label reading.

Common dashboard mistakes

  • Maximizing chart count rather than communication.
  • Assuming proximity automatically creates meaningful comparison.
  • Using a pie chart for detailed ranking.
  • Omitting titles, units, or legends.
  • Ignoring whether output is for a laptop, print report, or executive slide.
  • Allowing labels to overlap rather than using layout adjustment.

28. Python operator review

Arithmetic and logic

  • Arithmetic includes addition +, subtraction -, multiplication *, division /, and exponentiation **.
  • Logical operators are and, or, and not.
  • Comparison operators include ==, !=, >, <, >=, and <=.

Assignment versus equality — strongly emphasized

  • a = 5 assigns the right-hand value to the left-hand variable. It does not test equality.
  • a == 5 tests equality.
  • a += b means a = a + b; if a=5 and b=4, a becomes 9.
  • Analogous augmented assignments include -=, *=, /=, and **=.

Membership

  • item in collection returns True if the item is present.
  • item not in collection returns True if it is absent.
  • Practical example: checking whether a roll number occurs in a very large result list.

29. Variables and dynamic typing

Types mentioned include strings, integers, floating-point numbers, Booleans, lists, tuples, dictionaries, and objects/arrays.

Python normally infers a variable’s type from the assigned value; it does not require a prior declaration such as “integer” or “float.” For example, weight = 5.9 is inferred as floating-point, whereas roll_number = 10 is inferred as integer.

Students should know how to create and manipulate collections, including adding elements to lists, because visualization work relies on data preparation.

30. What is a Python library?

A library is a collection of prewritten Python code that provides useful functionality. Libraries prevent every user from reimplementing, testing, and debugging common operations such as a square-root calculation.

Typical use:

  1. Install a third-party library if it is not already available.
  2. Import the required library/module/class.
  3. Call a function.
  4. Pass required and optional arguments.
  5. Receive/plot the result.

Examples named: math, os, NumPy, Pandas, Matplotlib, Seaborn, Requests, scikit-learn, and NLTK.

31. Library hierarchy

Conceptual hierarchy:

Python language/runtime
└── library or package
    └── module/subpackage
        ├── functions
        ├── classes
        ├── variables
        └── constants
            └── user code calls/instantiates/reads them
  • Runtime/environment: where Python code executes.
  • Library/package: collection of related modules.
  • Module/subpackage: organized file/unit within a library.
  • Function: reusable behavior invoked with arguments.
  • Class: blueprint used to construct objects.
  • Variable: named stored value.
  • Constant: value intended not to change.
  • Argument/property: input or setting controlling function behavior.

Transcript correction: pyplot is a module of Matplotlib, not Pandas.

32. Imports, aliases, and the Matplotlib demonstration

import matplotlib.pyplot as plt
from matplotlib.figure import Figure

plt.rcParams["figure.figsize"] = (8, 4)

plt.plot([1, 2, 3], [10, 20, 30])
plt.title("Sample Plot")

33. Jupyter Notebook and kernel

  • A notebook combines Markdown notes, images, executable code cells, and outputs.
  • Shift+Enter executes the current code cell and moves forward; a Markdown cell is rendered rather than numerically executed.
  • Restarting the kernel and clearing outputs resets the current computational state/output display.
  • The kernel is the backend engine performing calculations. The browser is the frontend displaying the notebook and results.
  • Shutting down the kernel leaves a visible frontend that can no longer compute until connected to a running kernel.

35. Theory must guide tool output

The instructor explicitly connects earlier theory—clutter reduction, color, preattentive processing, and Gestalt principles—to Python plotting:

  • Defaults are only starting points.
  • Inspect every border, line, label, and axis.
  • Remove unnecessary pixels if they do not convey information.
  • Borders may be unnecessary in one chart but helpful for separating multiple plots.
  • A color’s meaning is contextual and cultural. Red may imply danger in many Western contexts but auspiciousness/prosperity in Chinese contexts.
  • Know the audience before encoding positive/negative meaning through color.
  • AI or software output still requires analyst judgment.

Practical Use Cases

Use case 1 — Restaurant tipping analysis

Use a scatter plot of total_bill against tip, then map time to style and day to hue. This can show whether the bill–tip relation differs across lunch/dinner or days. Use relplot(col="time") when a shared panel is crowded.

Use case 2 — Feature screening before regression

Create a pair plot for numeric variables, identify approximately linear predictor–target pairs, inspect distributions and outliers, and then use lmplot() to compare fitted relationships by group. Follow with numerical diagnostics before model selection.

Use case 3 — Customer/operational correlation audit

Select numeric columns, calculate a correlation matrix, and plot an annotated diverging heatmap. Use fixed vmin=-1, vmax=1, and a centered diverging palette when comparing correlation heatmaps.

Use case 4 — Seasonal demand matrix

Pivot long-form monthly sales or passenger data into month × year form. A heatmap reveals seasonality and year-over-year growth faster than reading the raw table. Reindex months into the desired calendar/fiscal order.

Use case 5 — Executive dashboard design

Group directly comparable time-based charts into one figure and separate a composition-only chart if print size makes it unreadable. Save figures with clear filenames and appropriate resolution.

Rapid Revision and Exam Checklist

Definitions to know

  • [ ] Scatter plot = joint distribution of two variables using one point per observation.
  • [ ] Heatmap = matrix plot where color intensity represents cell values.
  • [ ] Figure = complete Matplotlib canvas; Axes = individual plotting area.
  • [ ] Style controls aesthetics; context scales elements for paper/notebook/talk/poster.
  • [ ] Spines are plot borders.
  • [ ] Library = collection of prewritten code; module = organized component within it.
  • [ ] Kernel = backend computation engine for Jupyter.

Functions and parameters

  • [ ] sns.scatterplot(data, x, y, hue, size, style, palette, marker/color).
  • [ ] Numeric and categorical hue behave differently.
  • [ ] style is categorical even if its source dtype is numeric.
  • [ ] Same variable in hue + style gives accessible redundant encoding.
  • [ ] sns.relplot(..., col=..., kind="scatter") makes faceted scatter plots.
  • [ ] relplot() synchronizes semantic mappings across facets.
  • [ ] sns.heatmap(data, vmin, vmax, cmap, annot, linewidths, linecolor).
  • [ ] Raw data may require numeric selection + .corr() or .pivot_table().
  • [ ] sns.set_theme(), set_style(), set_context() set appearance.
  • [ ] axes_style() and plotting_context() inspect current dictionaries.
  • [ ] reset_defaults() returns to defaults.
  • [ ] despine() removes top/right spines; offset separates surviving spines; trim limits their range.
  • [ ] plt.subplots() creates figure and axes together.
  • [ ] plt.rcParams["figure.figsize"] affects future default figures.
  • [ ] tight_layout() reduces layout overlap.
  • [ ] savefig() saves the figure; use clear filenames for multiple outputs.

Interpretation questions

  • [ ] Straight-line scatter pattern suggests possible linear-regression suitability.
  • [ ] Curves, random clouds, clusters, outliers, or changing spread require caution.
  • [ ] Pair-plot off-diagonal = pair relationships; diagonal = individual distributions.
  • [ ] hue overlays colored groups; col creates separate panels.
  • [ ] Clipping is corrected by axis/range handling, not by removing data or changing colors.
  • [ ] Never treat the visible portion of a clipped plot as the full function/data behavior.
  • [ ] Heatmap rows and columns must both be meaningful.
  • [ ] Correlation diagonals equal 1.

Dashboard decisions

  • [ ] Line chart → trends over ordered time.
  • [ ] Stackplot → overall total plus changing composition; upper bands are harder to compare precisely.
  • [ ] Pie → approximate part-to-whole; bar chart is better for precise ranking.
  • [ ] Related time charts can be grouped; unrelated composition charts may deserve separation.
  • [ ] Optimize for audience, medium, labels, print size, and business question—not maximum chart count.

Python/live-session traps

  • [ ] = assigns; == tests equality.
  • [ ] a += b means a = a + b.
  • [ ] Exponentiation is **.
  • [ ] Membership uses in and not in.
  • [ ] Python infers types from assigned values.
  • [ ] pyplot belongs to Matplotlib.
  • [ ] Retype, run, modify, and inspect code; passive viewing is insufficient for practical mastery.

One-sentence final takeaway

A good visualization preserves the meaning and completeness of the data, applies consistent and audience-appropriate encodings, and removes only those visual elements that do not help the reader answer the intended question.

Review-Week Augmentation

Priority topic: line charts for time

The review repeatedly emphasizes the line chart as the default for change over ordered time: monthly revenue, stock price, population growth, temperature, and website traffic. It answers whether a measure is increasing/decreasing, where direction changes, and whether seasonality or recurring patterns exist. The connection communicates continuity; never connect unordered categories simply for appearance.

Dashboard chart caveats

  • A stacked area plot shows overall growth, mix, and contribution, but middle/upper bands have changing baselines and are less precise than separate lines.
  • A pie chart may show one regional-sales snapshot only when the categories form one whole; it does not show a trend.
  • One 2×2 dashboard supports cross-comparison only if panels remain legible and follow a logical scan path. Split figures when print size, labels, or audience focus require it.
  • Consistent colour and direct labelling reduce repeated legend lookup; tight_layout() addresses spacing but cannot fix a conceptually poor layout.

Business-question frame

Trend over time → line. Total plus changing mix → stacked area with caveat. One small part-to-whole snapshot → pie. Relationship between two numeric variables → scatter. State the audience, task, and limitation before defending the dashboard arrangement.
