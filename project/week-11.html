1. Overview

This quiz focuses on selecting the correct statistical analysis method based on the research objective.

The main concepts covered are:

  • Mediation analysis.
  • Moderation analysis.
  • Regression.
  • Independent samples t-test.
  • One-way ANOVA.
  • Levene’s test.
  • Bayes Factor interpretation.
  • Descriptive statistics.

The central principle:

The research question determines the statistical method, not the availability of a particular analysis tool.

2. Choosing the Correct Analysis

A researcher must identify:

  1. The type of variables involved.
  2. The relationship being tested.
  3. Whether the goal is prediction, comparison, or explanation.

Main decision framework:

Research Goal Appropriate Analysis
Compare two group means Independent samples t-test
Compare three or more group means One-way ANOVA
Predict an outcome from predictors Regression
Test indirect effects Mediation
Test conditional effects Moderation
Test whether a variable changes another relationship Interaction regression

3. Mediation Analysis

Concept

Mediation explains how or why one variable affects another.

The structure:

Independent Variable → Mediator → Dependent Variable

Example:

Store Attributes → Perceived Value → Customer Satisfaction

Question:

“Does Store Attributes improve satisfaction because it increases perceived value?”

Variables:

  • X \= Predictor.
  • M \= Mediator.
  • Y \= Outcome.

Mediation tests:

  1. Direct effect:

X → Y

  1. Indirect effect:

X → M → Y

4. Mediation in Jamovi

The appropriate tool:

MedMod add-on module

Why?

Standard regression can test individual paths, but MedMod directly estimates:

  • Indirect effects.
  • Bootstrap confidence intervals.
  • Mediation models.

Incorrect choices:

ANOVA

Used for group comparisons.

Not mediation.

Frequencies/Contingency tables

Used for categorical relationships.

Not mediation.

Basic regression alone

Can estimate paths but is not the direct mediation workflow.

5. Regression Analysis

Purpose

Regression predicts an outcome using one or more predictors.

General form:

Outcome \= Intercept + Predictor effects + Error

Example:

Predict:

Customer Satisfaction

from:

  • Store Attributes.
  • Product Attributes.

6. Simple Linear Regression

Used when:

  • One predictor.
  • One continuous outcome.

Example:

Perceived Value → Customer Satisfaction

Question:

“Does perceived value predict satisfaction?”

Correct analysis:

Simple linear regression.

Output includes:

  • Regression coefficient.
  • Direction of effect.
  • Significance.
  • Prediction equation.

7. Multiple Linear Regression

Used when:

  • Multiple predictors.
  • One continuous outcome.

Example:

Predict Perceived Value from:

  • Store Attributes.
  • Product Attributes.

Model:

PV \= b0 + b1(Store Attributes) + b2(Product Attributes)

Advantages:

  • Estimates unique contribution of each predictor.
  • Controls for other predictors.

8. Regression vs Correlation

Correlation

Answers:

“Are two variables related?”

Does not create prediction equations.

Regression

Answers:

“Can one variable predict another?”

Provides:

  • Equation.
  • Direction.
  • Effect size.

Example:

Correlation:

PV and CS are associated.

Regression:

PV predicts CS.

9. Moderation Analysis

Concept

Moderation explains when or for whom an effect occurs.

Structure:

Predictor × Moderator → Outcome

Example:

Store Attributes → Customer Satisfaction

Effect depends on:

Variety Seeking.

Question:

“Does the impact of Store Attributes change depending on customer variety-seeking behaviour?”

10. Testing Moderation

The correct method:

Regression with interaction term.

Model:

Customer Satisfaction \=
Store Attributes +
Variety Seeking +
(Store Attributes × Variety Seeking)

The interaction term determines whether:

  • The predictor effect changes across moderator levels.

11. Why Not Split Groups?

A common mistake:

Creating:

  • High variety seekers.
  • Low variety seekers.

Then running separate regressions.

Problem:

  • Reduces statistical power.
  • Loses information.
  • Does not formally test interaction.

Better:

Use continuous moderation with interaction regression.

12. Independent Samples t-test

Purpose

Compares the means of two independent groups.

Example:

Compare satisfaction between:

  • Men.
  • Women.

Variables:

Grouping variable:

Categorical.

Example:

Gender.

Outcome:

Continuous.

Example:

Satisfaction score.

13. Levene’s Test

Purpose

Checks equality of variances before interpreting t-test results.

Null hypothesis:

The groups have equal variances.

Interpretation:

p > 0.05

Fail to reject null.

Equal variance assumption acceptable.

p \< 0.05

Variance differs.

Use unequal variance correction.

Important:

Levene’s test does NOT test:

  • Equal means.
  • Normality.
  • Group differences.

14. Bayes Factor in t-tests

Bayes Factor compares evidence between hypotheses.

Example:

BF \= 0.14

Interpretation:

Evidence favors the null hypothesis.

Meaning:

Evidence supports no meaningful group difference.

Important:

A non-significant p-value alone does not prove equality.

Bayes Factor provides additional evidence.

15. One-Sample t-test

Purpose

Tests whether a sample mean differs from a known benchmark.

Example:

Customer satisfaction average:

Observed mean:

3.52

Target:

4.0

Research question:

“Is the population average different from 4?”

Correct test:

One-sample t-test.

16. Independent t-test vs One-Sample t-test

Test Purpose
One-sample t-test Compare sample mean to fixed value
Independent samples t-test Compare two group means

Examples:

One sample:

“Is satisfaction different from target 4?”

Independent:

“Do men and women differ in satisfaction?”

17. ANOVA

Purpose

Compares means across multiple groups.

Example:

Customer Satisfaction across:

  • Age Group 1.
  • Age Group 2.
  • Age Group 3.
  • Age Group 4.

One-way ANOVA:

One categorical factor.

18. ANOVA vs Regression

They can answer similar questions.

ANOVA:

Focus:

Group differences.

Example:

Do age groups differ in satisfaction?

Regression:

Focus:

Prediction.

Example:

How do predictors influence satisfaction?

19. Choosing Regression Instead of ANOVA

If predictors are composite continuous scores:

Example:

  • Store Attributes score.
  • Product Attributes score.

Outcome:

Customer Satisfaction.

Use:

Multiple linear regression.

20. Descriptive Statistics

Before advanced analysis, summarize data.

Important measures:

  • Mean.
  • Standard deviation.
  • Skewness.
  • Kurtosis.

21. Mean

Meaning

Average score.

For Likert composites:

Represents typical agreement level.

Example:

Mean \= 3.8

Interpretation:

Average customer agreement is around 3.8.

22. Standard Deviation

Meaning

Response spread.

Small SD:

Responses are similar.

Large SD:

Responses vary widely.

23. Skewness

Purpose

Measures distribution asymmetry.

Positive skew:

Longer right tail.

Negative skew:

Longer left tail.

24. Kurtosis

Purpose

Measures distribution shape and tail heaviness.

Used for:

Understanding distribution shape.

Important:

Mean and SD summarize the data.

Skewness and kurtosis describe distribution shape.

25. Common Misconceptions

Misconception 1:

Correlation proves causation.

Reality:

Correlation only shows association.

Regression improves prediction but still requires research design for causal claims.

Misconception 2:

Mediation means simple regression.

Reality:

Mediation specifically tests indirect pathways.

Misconception 3:

Moderation means comparing groups.

Reality:

Moderation tests whether an effect changes depending on another variable.

Misconception 4:

Levene’s test checks mean differences.

Reality:

It checks variance equality.

Misconception 5:

Non-significant t-test proves groups are identical.

Reality:

It means insufficient evidence of difference.

Bayes Factor can provide evidence supporting no difference.

Misconception 6:

ANOVA is always better than regression.

Reality:

Choice depends on research objective.

  1. Statistical methods should match research questions.

Case Study

DataSense LLC recently analyzed mobile application satisfaction ratings to decide if gender influences user experience. Analyst Priya collected ratings from male and female customers and performed an Independent Samples t-test. She first tested the homogeneity of variances using Levene’s test (Null (H0): no difference in variance between the two groups), finding a Levene’s test p-value > 0.05, so the assumption was met. The Student’s t-test then yielded a p-value > 0.05 (male mean satisfaction 3.63 u2014 female mean satisfaction 3.66), leading to a failure to reject H0. A Bayes Factor of 0.137 (\< 1) provided strong additional evidence favouring the null hypothesis. Marketing lead Jackson argued that if gender does not differentiate satisfaction, resources might be allocated elsewhere, while Priya suggested further subgroup analyses.To probe deeper, the team examined satisfaction across three age bands (18-29, 30-49, 50+). They conducted a One-Way ANOVA (Null (H0): all group means are equal) and obtained p \= 0.04, prompting rejection of H0. A post-hoc test using Tukey identified a significant difference between the 18-29 and 50+ segments. Product manager Elena saw this as a clear signal to tailor features, whereas finance director Ravi cautioned that budget constraints might limit targeted campaigns.At the decision point, DataSense must choose among three options: continue with a gender-neutral strategy since the demonstration of analysis indicates no significant difference; launch a pilot marketing campaign aimed at the 18-29 segment based on ANOVA findings; or perform a Chi-square test of association on categorical variables (for example, payment method vs feature use) to uncover other differentiators. Students should apply if-then reasoning: if budget allows, pilot an age-based campaign; if not, maintain the current approach.

Variances differ.

22. Common Misconceptions

Misconception 1:

A non-significant t-test proves there is no difference.

Reality:

It means insufficient evidence of difference.

Misconception 2:

Levene’s test checks whether means are equal.

Reality:

It checks whether variances are equal.

Misconception 3:

ANOVA identifies the exact groups that differ.

Reality:

Post-hoc tests identify specific differences.

Misconception 4:

A significant p-value means immediate action.

Reality:

Business impact and feasibility must also be considered.

Misconception 5:

Bayes Factor replaces p-values.

Reality:

Bayes Factor complements traditional hypothesis testing.

Misconception 6:

One demographic variable explains all customer behaviour.

Reality:

Different variables reveal different patterns.

Week 11 Exam Appendix — Regression, Mediation, Moderation, Group Comparisons, and Decision-Oriented Interpretation

A. End-to-end analysis map

Week 11 moves from validated measures to business conclusions:

Clean and validate data → compute construct scores → inspect descriptives/benchmarks → test direct effects with regression → test mediation/moderation → compare groups with t-tests/ANOVA → test categorical association with chi-square → translate statistical evidence into action.

The software is secondary. The exam emphasis stated in the live session is likely to be which analysis is appropriate, what output means, and how it helps solve the problem, not which Jamovi button to click.

B. Practical workflow for the retail case

1. Compute construct scores

After item reliability and validity are satisfactory, aggregate the retained items for:

  • store attributes (SA);
  • product attributes (PA);
  • perceived value (PV);
  • variety seeking (VS);
  • customer satisfaction (CS).

The demonstration uses a mean score for each construct. For five SA items, SA = mean(SA1…SA5). A mean preserves the original Likert range and is easy to compare with a benchmark. Do not aggregate invalid items merely because they share a label.

2. Descriptive interpretation

  • Mean: average construct level. In the case, SA was about 3.52; VS was about 3.93–3.94, suggesting relatively strong variety-seeking tendencies.
  • Standard deviation: dispersion/disagreement. Higher SD means respondents differ more in their perceptions; VS showed relatively greater disagreement than some other constructs.

Skewness and kurtosis are useful for distribution/assumption checks, but the lecturer emphasized mean and SD for initial managerial description.

Use case: A mean of 3.52 does not itself prove that the entire population meets the retailer’s desired benchmark of 4. The retailer should inspect the population-inference test and the item-level weaknesses before declaring store performance “good.”

3. One-sample t-test as benchmark test

Use a one-sample t-test when comparing a sample mean with a specified target/population benchmark.

  • H0: μ = benchmark
  • H1: μ ≠ benchmark (or directional </> where justified beforehand)

For SA, compare the sample mean around 3.52 with a desired benchmark such as 4. A significant result indicates the mean differs from the benchmark; it does not prove practical inadequacy without interpreting direction and size. The transcript experiments with nearby test values (e.g., 3.5/3.6) to illustrate the plausible population range.

Statistical caution: The reported mean difference is sample mean − test value; a confidence interval around the mean/difference is more informative than guessing population limits from one difference value. “Fail to reject H0” does not prove exact equality.

C. Choosing and interpreting regression

1. Correlation versus regression

  • Correlation: symmetric strength/direction of association; no predictor/outcome direction is imposed.
  • Regression: estimates the directional predictive contribution of one or more IVs to a DV, holding other included predictors constant.

Use regression when theory specifies PA/SA as predictors and PV/CS as outcomes. Correlation alone cannot provide the case’s full predictive/managerial interpretation.

2. Simple versus multiple linear regression

  • Simple regression: one IV and one DV, e.g., PV→CS.
  • Multiple regression: two or more IVs predict one DV, e.g., PA and SA→PV; PA and SA→CS.

The case therefore needs at least:

  1. PV = b0 + b1(PA) + b2(SA) + error
  2. CS = b0 + b1(PA) + b2(SA) + error
  3. CS = b0 + b1(PV) + error

A combined model may include PA, SA and PV predicting CS, but mediation is not established merely because all appear in one regression.

3. Regression assumptions and diagnostics

Check in proportion to the model:

  • linearity between predictors and outcome;
  • independent observations/errors;
  • approximately normal residuals, assessed with residual Q–Q plots rather than requiring every raw variable to be perfectly normal;
  • homoscedasticity/constant residual variance;
  • absence of severe multicollinearity (VIF; transcript mentions ideal below about 3.3 and often acceptable below 5);
  • no highly influential outliers;
  • correct model specification.

The least-squares line minimizes squared residuals. RMSE measures typical prediction error in outcome units; lower is better only relative to the outcome scale or competing models, not through a universal “below .3 is good” cutoff. R² is the proportion of outcome variance explained; adjusted R² is preferable when comparing models with different predictor counts.

4. Reading output

Interpret:

  1. overall model test (often an F/ANOVA table);
  2. R²/adjusted R² and RMSE;
  3. each coefficient’s sign, magnitude, CI and p-value;
  4. standardized coefficients when comparing predictors measured on different scales;
  5. assumptions and practical meaning.

The case reported significant PA and SA prediction of PV, with standardized contributions roughly PA .322 and SA .269 in one model; in another demonstrated path SA’s standardized effect was about .364. PV significantly predicted CS at roughly .335. Exact coefficients belong to their specific fitted model—do not mix values across different regressions.

Exam interpretation: “A standardized beta of .322 means a one-SD increase in PA is associated with a .322-SD increase in PV, holding the other predictor constant.” It does not mean a 32.2% causal increase unless design and units justify that claim.

Significance plus moderate/weak explanatory power means the relationship likely exists, but substantial variance remains unexplained; managers should improve selected attributes and investigate omitted causes rather than claim a complete solution.

D. Mediation analysis

1. Logic

Mediation tests how/why X affects Y through M:

X → M (path a); M → Y controlling X (path b); indirect effect = a × b; direct effect = c′; total effect = c′ + ab.

In the retail model, PV mediates:

  • SA→PV→CS;
  • PA→PV→CS.

The null says the indirect effect is zero. Prefer a bootstrap confidence interval for ab; mediation is supported when the indirect-effect interval excludes zero. Individual significant paths alone are not the best formal test of the indirect effect.

2. Case interpretation

For one demonstrated route, about 16.51% of the total effect was transmitted through PV, while the rest was direct. Both PA and SA showed significant indirect paths through PV. This yields an actionable mechanism: product/store improvements should be designed to make customers perceive better benefit relative to sacrifice, not merely improve operational attributes invisibly.

3. Types of mediation

  • Full/indirect-only mediation: indirect effect exists and the direct effect becomes non-significant/near zero after M is included.
  • Partial mediation: both indirect and direct effects remain.
  • Complementary: direct and indirect effects are significant and have the same sign.
  • Competitive: both significant but have opposite signs.

The retail paths were interpreted as complementary partial mediation: attributes influence satisfaction directly and also positively through value.

Caution: Modern mediation inference does not require the direct effect to be significant before mediation, and a non-significant direct effect does not by itself prove “complete causation through M.” Temporal ordering and confounding still matter.

E. Moderation analysis

1. Logic

Moderation tests when/for whom X’s effect changes:

Y = b0 + b1X + b2W + b3(X×W) + error

The coefficient b3 tests moderation. Here W is variety seeking. Test each theoretically specified path; the tool used in the video analyzed them separately.

Simple slopes are often examined at low (−1 SD), mean and high (+1 SD) W. A graph helps show conditional slopes, but significance comes from the interaction/simple-slope output and confidence intervals, not visual appearance alone.

2. Case interpretation

Several VS interactions were not significant (p > .05; CIs containing zero), including demonstrated store-attribute paths. One product-attribute interaction was interpreted as significant and positive: as VS increased, product attributes became more influential for satisfaction. Managerial implication: variety seekers may respond to stronger assortment, novelty, display, availability or quality—subject to item-level evidence and cost-benefit testing.

Do not claim a moderator effect when only the direct effect of X is significant. The X×W term is the test.

F. Group-comparison tests

1. Independent-samples t-test

Use when comparing a continuous outcome across two independent groups, e.g., male versus female satisfaction or online- versus offline-preferring customers.

  • H0: μ1 = μ2
  • H1: μ1 ≠ μ2

In the case, male CS was about 3.63 and female CS about 3.66; the difference was not significant, so the evidence did not justify gender-differentiated satisfaction strategy.

Levene’s test

  • p > .05: do not reject equal variance; Student’s pooled t-test is usable.
  • p < .05: equal variance is doubtful; use Welch’s t-test/appropriate unequal-variance row.

Levene’s p-value concerns variance equality, not group-mean equality.

Report group means/SDs, t, df, p, CI and effect size (e.g., Cohen’s d), not p alone.

2. Bayes factor

A Bayes factor compares relative evidence for models/hypotheses, unlike a frequentist p-value. For example, BF10 > 1 favors H1 over H0; BF01 > 1 favors H0. The reciprocal convention must be identified before interpreting. Values near 1 are inconclusive; increasing thresholds indicate stronger evidence. It does not directly report “the probability H0 is true” unless combined with explicit prior odds.

3. Paired-samples t-test

Use for linked observations, e.g., the same students’ marks before and after training. It is not interchangeable with the independent t-test.

4. One-way ANOVA

Use for a continuous outcome across three or more independent levels, e.g., satisfaction across age groups.

  • H0: μ1 = μ2 = … = μk
  • H1: at least one mean differs

The omnibus F-test only establishes that some difference exists. Follow a significant result with post-hoc tests:

  • Tukey when equal variances are reasonable;
  • Games–Howell when unequal variances/sample sizes warrant it.

The transcript’s omnibus age result was close to but above .05 (around .08), yet it discusses a marked pairwise difference between ages 40–55 (mean about 3.58) and above 55 (about 3.9). Treat this cautiously: unplanned pairwise claims after a non-significant omnibus test increase false-positive risk. A prespecified contrast or multiplicity-adjusted post-hoc result can still be discussed with transparent caveats.

Report F, dfs, p, effect size (η²/ω²), group descriptives, assumption method and adjusted pairwise comparisons.

Test Comparison

G. Chi-square test of association

Use a contingency-table chi-square test for association between two categorical variables, e.g., gender × preferred shopping format.

  • H0: variables are independent/no association.
  • H1: variables are associated.

Requirements include independent observations, mutually exclusive categories and adequate expected counts. If counts are small, combine defensible categories or use Fisher’s exact test.

The case did not establish a significant gender–shop-preference association, nor a clear age-level preference association. Do not test categorical pairs without conceptual logic (e.g., treating age and gender as if one changes the other). Report χ², df, p, expected-count diagnostics and Cramér’s V for strength.

H. DataSense strategic decision case

DataSense compares campaign response/customer outcomes:

  • gender has two groups → independent t-test;
  • age has multiple groups → one-way ANOVA plus justified post-hoc comparisons;
  • categorical segment × categorical preference → chi-square;
  • Bayes factor adds evidence about H0 versus H1.

If gender differences are negligible, continue a gender-neutral strategy rather than invent segmentation. If an age group appears promising but evidence is borderline, conduct a limited age-targeted pilot, monitor incremental response/profit and avoid a costly full rollout. Statistical significance is not business significance: calculate expected uplift, segment size, campaign cost, operational feasibility and downside risk.

If–then decision rule:

  • If budget permits, pilot the age-based campaign and measure causal uplift.
  • If budget is limited, retain the broad strategy while collecting more targeted evidence.
  • Use chi-square only for categorical association questions, not as a substitute for comparing means.

I. Measurement quality recap from the live session

Before hypothesis testing:

  1. General quality: missingness, coding errors, outliers, independence/randomness and sample representativeness.
  2. Reliability: inter-item/internal consistency (Cronbach’s alpha) and composite reliability, typically sought above .70 as a guideline.
  3. Item/convergent validity: adequate standardized loadings (often ≥.50 contextually) and AVE ≥ .50.
  4. Discriminant validity: HTMT below .85 (sometimes .90 depending on field).

The live SEM demonstration reported example values such as alpha .825, AVE .568, PA reliability about .936, PA AVE about .84, and HTMT about .359, supporting the demonstrated measures. The lecturer momentarily said “HTMT should be more than .85,” then correctly interpreted the requirement as less than .85.

Important distinctions:

  • Cronbach’s alpha is not “item-to-item correlation” itself; it is an internal-consistency coefficient influenced by inter-item covariance and item count.
  • Composite reliability is not ordinarily called “ordinal alpha”; they are distinct reliability concepts/estimators.
  • Face/content validity are expert/qualitative judgments about apparent relevance/domain coverage, not statistical external validity in the generalizability sense.

Jamovi SEM labels exogenous variables as predictors determined outside the modeled system and endogenous variables as modeled outcomes. For measurement-only assessment, constructs can be entered to obtain reliability/validity indices, but a correctly specified CFA/SEM remains preferable when interpreting model fit and paths.

Two categorical variables; independence/mutual exclusivity/expected counts; χ²/p/Cramér’s V; use Fisher when sparse; give shop-preference example.

Explain data cleaning, alpha/CR, loadings, AVE and HTMT. Poor measurement invalidates construct scores and later regression/mediation.
