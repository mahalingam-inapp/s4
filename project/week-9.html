2. Data Management Before Analysis

Before performing any statistical test, researchers must ensure that:

  1. Data values are valid.
  2. Variables are correctly coded.
  3. Missing values are identified.
  4. Measurement levels are correctly assigned.

3. Data Screening and Cleaning

Purpose

Data screening identifies errors before analysis.

Examples:

  • Impossible values.
  • Incorrect coding.
  • Missing entries.
  • Outliers.

Example

A Likert item uses:

1 \= Strongly Disagree
5 \= Strongly Agree

A respondent enters:

50

This is invalid.

Correct action:

  1. Identify the error.
  2. Check the original response.
  3. Correct the value or mark it as missing.

Incorrect approaches:

Creating averages immediately

Why incorrect?

The invalid value should be fixed before scale construction.

Standardizing values

Why incorrect?

A z-score transformation does not correct incorrect data.

Recode during import

Why incorrect?

The problem is not coding format but invalid data.

4. Variable Measurement Levels in Jamovi

Jamovi requires researchers to define how variables should be treated.

Common measurement levels:

  1. Nominal.
  2. Ordinal.
  3. Continuous.
  4. ID.

5. Nominal Variables

Definition

Categories with no natural order.

Examples:

  • Gender.
  • Department.
  • Country.
  • Customer type.

Example:

Gender:

1 \= Male
2 \= Female

Although numbers are used, they do not represent quantity.

Correct setting:

Nominal

Incorrect:

Continuous.

Reason:

A value of 2 does not mean “twice” value 1.

6. Ordinal Variables

Definition

Categories with meaningful order but unequal intervals.

Examples:

  • Satisfaction levels.
  • Likert responses.
  • Education levels.

Example:

Customer satisfaction:

1 \= Very dissatisfied

5 \= Very satisfied

The order matters:

5 > 4 > 3 > 2 > 1

But the distance between categories is not guaranteed equal.

Correct Jamovi setting:

Ordinal

7. Likert Scale Measurement

A Likert item:

Example:

“I am satisfied with the service.”

Responses:

1–5

Traditional measurement:

Ordinal.

Reason:

Responses represent ordered categories.

However:

In many practical analyses, multiple Likert items combined into a scale may be treated as approximately continuous.

Example:

Five satisfaction items averaged into:

Customer Satisfaction Score.

Important distinction:

Single Likert item:

Usually ordinal.

Composite scale:

Often treated as continuous.

8. Continuous Variables

Definition

Variables measured numerically with meaningful distances.

Examples:

  • Age.
  • Income.
  • Sales.
  • Satisfaction composite score.

Values can be averaged and mathematically compared.

9. ID Variables

Definition

Identifiers used only for records.

Examples:

  • Student ID.
  • Customer ID.
  • Respondent number.

They are not analysed as measurement variables.

10. Defining Value Labels

Numeric coding should include labels.

Example:

Gender:

1 \= Male

2 \= Female

Without labels:

The analysis output becomes difficult to interpret.

Correct setup:

Measurement level:

Nominal.

Labels:

1 Male

2 Female.

11. Handling Missing Values

Missing responses must be identified.

Example:

999 \= No response.

Correct setup:

Measurement:

Nominal.

Labels:

1 \= Male

2 \= Female.

Missing value:

Why?

Jamovi will exclude missing values from analysis.

Incorrect:

Leaving 999 as a valid category.

Problem:

The software thinks “999” is a real group.

12. Composite Scale Construction

Many psychological and business concepts cannot be measured with one question.

Examples:

  • Customer satisfaction.
  • Service quality.
  • Engagement.

Researchers use multiple items.

Example:

Customer Satisfaction:

CS1

CS2

CS3

CS4

CS5

A combined score is created:

Customer Satisfaction Average:

(CS1 + CS2 + CS3 + CS4 + CS5) / 5

13. Why Create Composite Scores?

Advantages:

  • More reliable measurement.
  • Reduces effect of individual item errors.
  • Represents the overall construct.

Incorrect approaches:

Categorizing items too early

Example:

Convert satisfaction into:

Low / Medium / High.

Problem:

Loss of information.

Normalizing before combining

Problem:

Not usually required for simple scale creation.

14. Regression Variable Setup

Regression examines prediction relationships.

Basic structure:

Dependent Variable (Outcome)

←

Independent Variables (Predictors)

Example:

Research question:

Do product attributes and store attributes predict customer satisfaction?

Correct model:

Outcome:

Customer Satisfaction.

Predictors:

  • Product Attributes.
  • Store Attributes.

Incorrect:

Customer Satisfaction predicting Product Attributes.

That reverses the model.

15. Regression vs Correlation

Correlation

Question:

Are two variables related?

Example:

Product quality and satisfaction.

Regression

Question:

Can one or more variables predict an outcome?

Example:

Do product and store attributes predict satisfaction?

Regression identifies:

  • Predictors.
  • Outcome.
  • Effect strength.

16. Jamovi Interface

Jamovi provides an integrated workspace.

A useful feature:

Data and analysis results can appear together.

This allows:

  • Viewing data.
  • Checking results.
  • Reviewing changes.

without constantly switching screens.

17. Measurement Model vs Structural Model

A critical research concept:

Measurement Model

Question:

“Are we measuring the constructs correctly?”

Example:

Do survey items correctly measure:

  • Customer satisfaction?
  • Service quality?

Methods:

  • Reliability analysis.
  • CFA.

Structural Model

Question:

“Are relationships between constructs supported?”

Example:

Does service quality influence satisfaction?

Methods:

  • Regression.
  • SEM paths.
  • Mediation.
  • Moderation.

18. Important Methodological Mistake

A common error:

Testing relationships before verifying measurement quality.

Example:

A researcher runs:

Customer Quality → Satisfaction

and finds significance.

But:

Are the items actually measuring customer quality?

Unknown.

Correct order:

  1. Validate measurement.
  2. Test relationships.

19. Reliability and Validity

Reliability

Question:

Are items consistent with each other?

Example:

Cronbach’s Alpha.

Validity

Question:

Are we measuring the correct concept?

Examples:

  • Content validity.
  • Construct validity.
  • CFA.

A significant relationship does not prove valid measurement.

20. Confirmatory Factor Analysis (CFA)

Purpose

Tests whether data fits a proposed measurement model.

Example:

Theory says:

Customer Satisfaction has five indicators.

CFA tests:

Do CS1–CS5 actually represent satisfaction?

CFA evaluates:

  • Factor loadings.
  • Model fit.
  • Construct validity.

21. CFA in Jamovi

Basic Jamovi does not provide full CFA functionality.

Required:

SEMLj module/plugin.

Correct workflow:

  1. Open Jamovi library.
  2. Install SEMLj.
  3. Access CFA and SEM analyses.

22. Factor Analysis Modules

Important distinction:

Exploratory Factor Analysis (EFA)

Purpose:

Discover underlying factors.

Question:

“What factors exist?”

Confirmatory Factor Analysis (CFA)

Purpose:

Test predefined factor structure.

Question:

“Does my proposed model fit?”

Although both involve factors, CFA requires SEM functionality.

23. CFA vs Regression

CFA Regression
Validates measurement Tests prediction
Uses latent constructs Uses variables
Measurement model Structural model

Example:

CFA:

Do five items measure satisfaction?

Regression:

Does satisfaction predict loyalty?

Numbers always mean continuous data.

Reality:

Numbers can represent categories.

Example:

Gender:

1 and 2 are labels, not quantities.

Misconception 2:

Invalid values can be fixed by transformation.

Reality:

Errors must be corrected first.

Misconception 3:

Significant relationships prove good measurement.

Reality:

Measurement validity must be established separately.

All Likert data is continuous.

Reality:

Individual Likert items are usually ordinal.

Composite scales may be treated as continuous.

Misconception 5:

Factor analysis automatically means CFA.

Reality:

EFA explores; CFA confirms.

Case Study

Maria and James work in Prof Lee’s marketing lab at Apex University. They have collected survey data from 120 participants, including variables: ID (continuous), Gender (nominal: 1=Male, 2=Female), ShopPref (nominal: 1=Offline, 2=Online), Satisfaction (continuous), AgeGroup (ordinal: 1–4). In Jamovi they click the Variables tab, assign each variable a short name (e.g., SAT, SEX), specify measurement types (Nominal / Continuous / Ordinal), set data types (Integer / Decimal), define levels for categorical variables, and assign missing values (e.g., 999). This ensures proper application of statistical methods.After importing the data, they run descriptive statistics: mean, SD, skewness, kurtosis for SAT (mean=3.8, SD=0.9, skewness=0.4, kurtosis=–0.2), and frequency counts for ShopPref (Offline=70, Online=50). To test whether satisfaction differs by ShopPref, they conduct an independent samples t-test yielding t(118)=2.15, p=0.034. They also set up a one-way ANOVA to compare SAT across AgeGroup categories and review Levene’s test for homogeneity of variance before interpreting results.At the decision point, the team must choose among three paths: a factorial ANOVA including a Gender×ShopPref interaction, a multiple regression with dummy-coded AgeGroup and Gender predictors, or installing the GAMLj module to run a mixed linear model if repeated measures are added. Maria prefers the straightforward ANOVA for clear group comparisons, James argues that regression will allow simultaneous assessment of predictors, and Prof Lee emphasizes checking diagnostic outputs and interpretability in the final report. Students must weigh trade-offs and select the most informative analysis approach.

17. Independent Samples t-Test

Purpose

Compares mean differences between two independent groups.

19. Understanding p-value

The p-value indicates:

How likely the observed difference would occur if there were actually no group difference.

Common rule:

p \< 0.05:

Statistically significant.

p > 0.05:

Not statistically significant.

Important:

Statistical significance does not indicate practical importance.

20. One-Way ANOVA

Purpose

Compares means across three or more groups.

Apex Example:

Compare satisfaction across:

AgeGroup 1

AgeGroup 2

AgeGroup 3

AgeGroup 4

Why not multiple t-tests?

Multiple tests increase the chance of false positives.

ANOVA compares groups together.

21. ANOVA Logic

ANOVA compares:

Between-group variation

Differences between age groups.

Within-group variation

Differences among individuals in the same group.

The F-statistic evaluates whether group differences are larger than expected by chance.

22. Levene’s Test

Purpose

Checks homogeneity of variance.

Assumption:

Groups should have similar variance.

Interpretation:

If Levene’s test is not significant:

Variance assumption is satisfied.

If significant:

Variances differ.

Alternative methods may be needed.

33. Choosing the Best Analysis

  • ANOVA.

If the question is:

Use:

  • Regression.

If the question is:

“Do effects differ between groups?”

Use:

  • Factorial ANOVA.

If the question is:

“Are measurements repeated over time?”

Use:

  • Mixed models.

Exam-Oriented Appendix

A. Practical examples and use cases

1. End-to-end retail research case

Management problem: footfall at a small retail shop is declining.

Research logic: Customer satisfaction is the focal dependent variable. Product attributes and store attributes are independent variables; perceived value is a mediator explaining how attributes create satisfaction; variety-seeking may change relevant effects. Hypotheses cover (a) measurement, (b) relationships among constructs, and (c) differences among customer groups.

Data plan: A cross-sectional questionnaire collects customer demographics, online/offline shopping preference, and five-point agreement responses for product attributes, store attributes, perceived value, variety-seeking, and satisfaction. Customers who have visited the shop are the sampling units.

Sampling: If the retailer has a customer list, it is the sampling frame. Simple random/lottery or systematic selection can give listed customers a known selection probability. Random selection is preferable for statistical representation but only represents the frame’s actual coverage.

Data sheet: One row per customer; one column per variable/item. Use short codes such as PA1–PA5, SA1–SA5, PV1–PV5, VS1–VS5, and CS1–CS5; code categories with labels (e.g., 1 = Male, 2 = Female) and retain a separate codebook.

Workflow: collect → code/import → define variable types and labels → screen missing/invalid/straight-line cases and outliers → check assumptions → verify reliability/validity → form composite scores → describe sample → compare groups → estimate relationships → interpret against the business problem.

2. Sample-size use case

Two approaches were illustrated:

  • For an SEM-type model with five latent constructs and about 29 observed variables, a calculator using anticipated effect size and power suggested a minimum around 172 in the lecture example.
  • For estimating a proportion at approximately 95% confidence with ±5% margin of error and conservative proportion p = .50, a very large/unknown population gives about 385 responses. Finite examples cited were about 278 for N = 1,000, 370 for N = 10,000, and 383 for N = 100,000.

These are not magic universal numbers. Required sample depends on objective, population size, design, effect size, power, number of parameters/constructs, desired precision, anticipated non-response, and estimator. Larger samples generally improve precision but cannot repair biased sampling or bad measurement.

3. Data cleaning and transformation use case

  • A value of 50 in a 1–5 item is invalid and should be traced to source/corrected or treated as missing—not automatically retained as an outlier.
  • A respondent selecting “neutral” for every item may be a straight-line response; investigate using predefined quality rules rather than deleting solely because answers are identical.
  • A missing-value code such as 999 must be declared to Jamovi as missing; otherwise it corrupts means and models.
  • Standardise values with z = (x − mean)/SD when variables measured in unlike units must be combined/compared. Do not standardise mechanically when all items already share an appropriate scale.
  • Compute a satisfaction average only after checking item direction, reverse scoring, reliability, and validity. Creating a composite immediately can conceal a poor measurement model.

5. Apex University case: descriptive and inferential workflow

The case uses 120 participants. Satisfaction has mean 3.8, SD 0.9, skewness 0.4, and kurtosis −0.2; shopping preference frequencies are Offline 70, Online 50.

  • Frequencies describe nominal ShopPref; mean/SD and distribution shape describe continuous SAT.
  • An independent-samples t-test comparing satisfaction by ShopPref reports t(118) = 2.15, p = .034. At α = .05, reject the equal-means null, but report group means/difference and confidence interval/effect size before claiming practical importance. The p-value neither measures effect size nor proves one mode is “better.”
  • One-way ANOVA compares satisfaction across more than two AgeGroup categories. A significant omnibus F only shows at least one mean differs; post-hoc comparisons locate the difference.
  • Levene’s test assesses equality of variances, not normality. A nonsignificant result generally supports the homogeneity assumption.

6. Choosing among factorial ANOVA, regression, and mixed models

Factorial ANOVA is ideal when the main question is group means and interactions, e.g.:

  • Does Gender affect satisfaction?
  • Does ShopPref affect satisfaction?
  • Does the effect of ShopPref depend on Gender (Gender × ShopPref)?

Multiple regression is ideal for simultaneous prediction/control:

Satisfaction = b₀ + b₁(ShopPref) + b₂(Gender) + b₃…(AgeGroup dummies) + error

It estimates each predictor’s unique contribution while holding others constant. Nominal predictors require dummy/indicator coding with a reference category.

Mixed linear models are needed when observations are dependent/nested or repeated—e.g., multiple satisfaction measurements from the same customer or customers nested within stores. Jamovi’s GAMLj module can support such models. Do not install/use a mixed model merely because it is advanced; ordinary ANOVA/regression is clearer when observations are independent and there is no multilevel/repeated structure.

7. Measurement model and structural model use case

  • Measurement model: Do CS1–CS5 adequately measure customer satisfaction? Check item loadings, reliability, convergent validity, and discriminant validity.
  • Structural model: Do product/store attributes and perceived value predict satisfaction, and does variety-seeking alter a path?

Do not average items and run regression before testing the measurement model. A structurally significant relationship between invalid composites is not trustworthy.

8. EFA and CFA use case

  • EFA: used when the factor structure is not sufficiently established; explores how items group in the sample.
  • CFA: tests a pre-specified measurement structure derived from theory—for example, five satisfaction items loading on one latent satisfaction factor.

The source describes EFA as exploring a sample structure and CFA as confirming whether the proposed structure fits. Ideally, explore and confirm on independent samples/split samples to avoid confirming a structure on the same evidence that generated it.

9. Three layers of quality assessment

  1. General data quality: distribution/normality where relevant, independent observations, correct measurement levels, adequate sample, missing values/outliers, and common-method concerns.
  2. Measurement quality: reliability and validity of multi-item constructs.
  3. Test-specific assumptions: e.g., homogeneity for group comparisons; linearity, residual assumptions, and multicollinearity for regression.

Practical rule: Check the assumptions of the specific estimator, not a ritual checklist applied identically to every test.

10. Assumption diagnostics in context

  • Normality: inspect histograms/Q–Q plots, skewness/kurtosis, and where appropriate Shapiro–Wilk or Kolmogorov–Smirnov. The lecture’s rough tolerance was absolute skewness/kurtosis around 2, but no cutoff is universal. For regression/t-tests the distribution of residuals or within-group outcome is usually more relevant than demanding every raw predictor be normal.
  • Independence: secure through design; participants should not coordinate answers. For ordered regression residuals, Durbin–Watson around 1.5–2.5 was given as a rule of thumb. Durbin–Watson is not a substitute for modelling known clustering/repeated measures.
  • Missing/outliers: identify codes, patterns, causes, and influence; choose deletion, imputation, correction, robust method, or sensitivity analysis transparently.
  • Homogeneity/homoscedasticity: Levene for group variance equality; residual plots for regression variance. If unequal, consider Welch tests/robust SEs rather than forcing equality.
  • Linearity: scatterplots/residual plots; required for linear correlation/regression paths.
  • Multicollinearity: predictors highly correlated make unique coefficients unstable. The lecture cited VIF below about 3.3 (or at least below 5) as a rule of thumb; interpret with tolerance/correlation and theory.

11. Common-method-bias example

When the same respondent, questionnaire, scale format, and collection moment measure all predictors and outcomes, shared method can inflate covariance. Procedural controls—separating sections/times/sources, neutral wording, anonymity, varying scale formats where justified—are preferable to relying only on a statistical test.

The lecture mentions Harman’s single-factor test (first unrotated factor should not dominate, often <50%) and a full-collinearity VIF threshold around 3.3/3.5. Treat these as diagnostics, not conclusive proof that common-method bias is absent.

B. High-yield distinctions

Data management vs data analysis

  • Management: coding, import, type/label definition, missing/outlier screening, transformation, computation.
  • Analysis: description, reliability/validity, hypothesis tests, group comparisons, prediction, modelling.

Nominal vs ordinal vs continuous vs ID in Jamovi

  • Nominal: unordered categories.
  • Ordinal: ordered categories with unknown/unequal gaps.
  • Continuous: interval/ratio-like numeric measurement where differences are meaningful.
  • ID: unique case label; excluded from substantive summaries/models.

Likert item vs Likert composite

A single 1–5 Likert item is ordinal. A validated sum/mean of multiple similarly directed items is commonly treated as approximately continuous for parametric analysis. It is not a ratio scale: “4” is not twice the attitude of “2,” and there is no true zero.

Missing value vs outlier vs invalid value

  • Missing: no usable observation.
  • Outlier: valid but unusually distant observation.
  • Invalid: impossible/out-of-range/error value.

Each needs a different decision; never delete all three under one automatic rule.

Sum vs mean composite

Both preserve relative standing when every respondent answers the same items. A mean retains the original response metric; a sum has a wider range. Missing-item rules must be declared, and reverse-coded items must be corrected first.

Correlation vs regression

  • Correlation symmetrically measures association between two variables.
  • Regression specifies an outcome and predictors, supports adjustment and prediction, and estimates unique coefficients.
  • Neither establishes causality without appropriate design and identification.

Reliability vs validity

  • Reliability: consistency of measurement (e.g., Cronbach’s alpha/composite reliability).
  • Validity: whether it measures the intended construct.
  • Reliability is necessary but not sufficient; consistently measuring the wrong concept is reliable but invalid.

Convergent vs discriminant validity

  • Convergent: indicators intended for the same construct share sufficient variance; factor loadings and AVE are common evidence.
  • Discriminant: theoretically different constructs are empirically distinct; Fornell–Larcker and HTMT were mentioned.

EFA vs CFA

  • EFA discovers a plausible factor pattern with fewer prior restrictions.
  • CFA tests a theory-specified item–factor pattern and overall fit.

Measurement model vs structural model

  • Measurement: construct ↔ indicators; “Are variables measured well?”
  • Structural: construct ↔ construct; “Are hypothesised relationships supported?”

t-test vs one-way ANOVA vs factorial ANOVA

  • t-test: one two-level grouping variable.
  • one-way ANOVA: one grouping variable with 3+ levels.
  • factorial ANOVA: two or more factors; estimates main and interaction effects.

ANOVA vs multiple regression

Both are general linear-model methods. ANOVA frames the problem around categorical group effects; regression naturally combines continuous and dummy-coded categorical predictors and controls. Choose the formulation clearest for the question.

Fixed-effects regression/ANOVA vs mixed model

A mixed model includes random effects to represent dependence from repeated measurements or clustering. Without that structure, the extra complexity is unnecessary.

p-value vs effect size vs confidence interval

  • p-value: compatibility/evidence against a null model under assumptions.
  • effect size: magnitude of difference/association.
  • confidence interval: precision and plausible range for the parameter.

All three answer different questions.

D. Rapid revision traps

  • ID = 1,2,3… is not continuous analysis data.
  • Category codes are labels, not quantities.
  • A single Likert item is not ratio-level merely because numbered 1–5.
  • 999 is not missing until software is told it is missing.
  • Data cleaning should precede composite construction and hypothesis testing.
  • Do not standardise or categorise variables automatically during import.
  • A 1 or 5 on a legitimate 1–5 item is not an outlier merely because extreme on that scale.
  • Large sample size does not cure non-representative sampling.
  • Shapiro–Wilk significance in a large sample should not be interpreted without plots/effect of departure.
  • Levene tests variance equality, not normality.
  • Nonsignificant Levene does not prove every ANOVA assumption.
  • p < .05 does not measure magnitude, importance, causality, or model quality.
  • A significant ANOVA does not identify which groups differ; use planned contrasts/post-hoc tests.
  • Regression direction does not alone prove causal direction.
  • High alpha can reflect redundant items; reliability does not guarantee validity.
  • Harman’s one-factor result cannot “prove” absence of common-method bias.
  • EFA and CFA on the same unpartitioned data provide weaker confirmation.
  • CFA validates measurement; regression tests observed/composite relationships. They are not substitutes.
  • Do not use a mixed model without repeated/nested dependence.
  • Diagnostics and interpretability are part of analysis, not optional decoration after obtaining p-values.
